# /command-code - команды типовых объектов в расширении

Контракт подключаемых команд БСП по памяти пишется неверно: в решениях задач команда регистрировалась с видом,
которого в конфигурации нет, и не появлялась на форме; "создание на основании" ограничивалось заполнением, а
самой команды не было. Не пиши этот код сам - опиши команду в JSON и запусти генератор. Он
сверит объекты, реквизиты и виды команд с выгрузкой и соберет расширение по образцам Демо БСП, проверенным
загрузкой в базу и синтаксическим контролем (обычным и расширенным).

**Вызов навыка генератор не запускает**: запиши описание JSON в файл (во временный каталог, не в проект) и
запусти команду Bash ниже; без строки `[OK]` в выводе работа не сделана.

```bash
python "$HOME/.claude/skills/1c-command-code/scripts/command-gen.py" -SpecPath "<описание.json>"
```

```json
{
  "configPath": "C:/путь/к/выгрузке",
  "extension": {"path": "C:/путь/к/расширению", "name": "ICOM_Команды"},
  "commands": [
    {"kind": "attached", "name": "СуммаВыбранных", "title": "Сумма выбранных заказов",
     "objects": ["Document._ДемоЗаказПокупателя"], "forms": "list",
     "result": {"query": "ВЫБРАТЬ\n\tСУММА(Т.СуммаДокумента) КАК Значение\nИЗ\n\tДокумент._ДемоЗаказПокупателя КАК Т\nГДЕ\n\tТ.Ссылка В (&Ссылки)",
                "template": "Сумма: %1", "format": "ЧДЦ=2; ЧН=0"}},
    {"kind": "basis", "source": "Document._ДемоЗаказПокупателя", "target": "Document._ДемоСчетНаОплатуПокупателю",
     "header": {"Контрагент": "Контрагент", "Договор": "Договор"}, "basisAttribute": "Основание",
     "tables": [{"source": "Товары", "target": "Товары", "columns": {"Номенклатура": "Номенклатура"}}]}
  ]
}
```

| Ключ | Что делает |
|---|---|
| `attached.objects` | объекты, к формам которых подключается команда |
| `attached.forms` | `list` - форма списка (по умолчанию), `object` - форма объекта, `all` - обе |
| `attached.result` | запрос по выбранным ссылкам `&Ссылки` с одним полем `КАК Значение`; результат по шаблону показывается пользователю |
| `attached.body` | строки кода серверного обработчика вместо `result`: `Ссылки` - массив выбранных, `ПараметрыВыполнения.Результат.Текст` - текст для пользователя |
| `attached.commandKind` | вид подключаемых команд из конфигурации; без него генератор регистрирует свой вид (`group.title`, по умолчанию "Действия") |
| `attached.writeMode`, `multiple` | `НеЗаписывать` (по умолчанию), `Записывать`, `Проводить`; множественный выбор - по умолчанию в списке |
| `basis.header` | реквизит получателя -> реквизит источника |
| `basis.tables` | табличная часть получателя и источника, колонки получателя -> колонки источника |
| `basis.basisAttribute` | реквизит получателя, куда записать ссылку на основание |

## Отказы - не обходи их

Генератор отказывает, если в выгрузке нет объекта, реквизита, табличной части, колонки или вида команды, и
перечисляет то, что есть. Это ответ по существу: например, в Демо БСП у заказа покупателя нет табличной части
"Товары" - копировать в счет нечего. Сообщи пользователю, чего нет, и сделай выполнимую часть (команду и
заполнение шапки). Не создавай реквизиты и табличные части ради задачи.

## Что генерируется

- `attached`: заимствованный `ПодключаемыеКомандыПереопределяемый` - `&После` на
  `ПриОпределенииКомандПодключенныхКОбъекту` (и `ПриОпределенииВидовПодключаемыхКоманд` для своего вида); серверный
  общий модуль расширения `<префикс>ПодключаемыеКоманды` с обработчиком `(ПараметрКоманды, ПараметрыВыполнения)`.
- `basis`: в менеджере источника `&После("ДобавитьКомандыСозданияНаОсновании")` (или своя процедура и регистрация
  источника в `СозданиеНаОснованииПереопределяемый`); в объекте получателя `&После("ОбработкаЗаполнения")` с
  проверкой типа основания. Реквизиты и табличные части получателя заимствуются: в модуле расширения
  незаимствованный реквизит недоступен, а присваивание ему молча создает локальную переменную.

## Когда НЕ применять

- Команда внешней (дополнительной) обработки БСП - навыки `1c-bsp-registration` и `1c-bsp-command`.
- Кнопка на одной форме без подсистемы подключаемых команд - навык `1c-form-code` (кнопка с командой формы).
- Печатная форма - `1c-print-form`.
