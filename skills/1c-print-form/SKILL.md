# /print-form - печатная форма по БСП

Контракт подсистемы Печать БСП по памяти пишется неверно: в решениях задач встречались выдуманные
`ДобавитьКомандуПечати`, `ПолучитьШаблон`, `ДоступныеВарианты`, собственная функция
`СведенияОВнешнейОбработке` вместо функции БСП и текст `[Параметр]` в ячейке без заполнения
"Шаблон" (оценка 14.10.2026). Не пиши этот код сам - бери образец ниже. Он построен по документу
`_ДемоРеализацияТоваров` Демо БСП и проверен синтаксическим контролем платформы (тонкий клиент, сервер,
внешнее соединение) на Демо БСП 8.5.1.

## Генератор - основной путь

**Вызов навыка генератор не запускает**: запиши описание JSON в файл и запусти команду Bash ниже; без строки `[OK]` в выводе генератора работа не сделана.

Опиши форму в JSON (файл во временном каталоге, не в проекте) и запусти генератор - он сверит поля с выгрузкой и
соберет все сам: расширение или обработку, заимствование, макет, модуль. Код руками не пиши.

```bash
python "$HOME/.claude/skills/1c-print-form/scripts/print-form-gen.py" -SpecPath "<описание.json>"
```

```json
{
  "variant": "extension",
  "configPath": "<каталог выгрузки конфигурации>",
  "object": "Document.РеализацияТоваровУслуг",
  "id": "ICOM_АктПриемаПередачи",
  "title": "Акт приема-передачи",
  "header": [ { "field": "Организация" }, { "field": "Контрагент", "title": "Покупатель" },
              { "field": "Контрагент.ИНН", "title": "ИНН" } ],
  "table": { "section": "Товары", "columns": [
      { "field": "Номенклатура", "title": "Товар" },
      { "field": "Количество", "total": true },
      { "field": "Сумма", "expr": "Количество * Цена", "total": true } ] },
  "amountInWords": { "field": "Сумма", "currency": "Валюта" },
  "extension": { "path": "<каталог расширения>", "name": "ICOM_Печать" }
}
```

| Ключ | Что это |
|---|---|
| `variant` | `extension` - форма типового документа или справочника в расширении; `external` - внешняя печатная форма (дополнительная обработка БСП), тогда вместо `extension` - `"external": { "outputDir": "<каталог src>", "name": "<имя обработки>" }` |
| `object` | `Document.<Имя>` или `Catalog.<Имя>` - имя из выгрузки, не синоним |
| `id` | идентификатор команды печати: без точек, запятых и пробелов, с префиксом |
| `header` | поля шапки: реквизит, стандартный реквизит (`Номер`, `Дата`, `Наименование`, `Код`) или путь через ссылку (`Контрагент.ИНН`) |
| `table` | табличная часть и колонки; `expr` - вычисляемая колонка из колонок этой табличной части; `total` - итог в подвале |
| `amountInWords` | сумма прописью: итоговая колонка или реквизит; с `currency` - функция БСП `РаботаСКурсамиВалют.СформироватьСуммуПрописью`, иначе `ЧислоПрописью` в рублях |

Пути в описании - абсолютные или относительно файла описания. Расширение, которого еще нет, генератор создает;
в существующее - добавляет форму.

**Отказ генератора - это ответ, а не ошибка, которую надо обойти.** Нет табличной части, колонки или реквизита -
генератор перечислит то, что есть. Не создавай недостающий реквизит или табличную часть ради печати: сообщи
пользователю, каких данных в конфигурации нет, и предложи вариант (другой объект, вычисление из имеющихся
колонок через `expr`, доработку структуры по его решению).

Что генератор выбирает сам, по выгрузке:

| У объекта в конфигурации | Что генерируется |
|---|---|
| есть `ДобавитьКомандыПечати` и `Печать` | перехватчики `&После` в модуле менеджера |
| есть только `ПриОпределенииНастроекПечати` | `&После` на нее (флаг `ПриДобавленииКомандПечати`) и свои `ДобавитьКомандыПечати`, `Печать` |
| печати нет | свои три процедуры и регистрация объекта перехватом `УправлениеПечатьюПереопределяемый.ПриОпределенииНастроекПечати` |

После генератора: внешнюю форму собери `1c-epf-build`; поля, которых нет в объекте (контактная информация,
данные из регистров), допиши в функцию формирования вручную. Проверено (15.10.2026): Демо БСП, УТ 11.5, УНФ 3.0 -
загрузка расширения, синтаксический контроль модулей обычный и расширенный, компиляция запросов.

Ниже - образцы, по которым построен генератор: для нетипового случая (у объекта уже перехвачена печать в
расширении, нужны данные из регистров) и для понимания того, что получилось.

## Когда применять

Конфигурация на БСП: в выгрузке есть общие модули `УправлениеПечатью` и
`УправлениеПечатьюПереопределяемый`. Для конфигурации без БСП образца здесь нет - сообщи об этом
пользователю.

| Задача | Вариант |
|---|---|
| печатная форма документа (справочника) конфигурации или расширения | A - модуль менеджера |
| печатная форма, которую подключают через "Дополнительные отчеты и обработки", без изменения конфигурации | B - внешняя печатная форма |

## Макет

Макет добавляй навыком `1c-template-add` (тип `SpreadsheetDocument`, имя `ПФ_MXL_<Имя>`), содержимое -
навыком `1c-mxl-compile`. Вручную `Template.xml` не пиши.

Области - именованные строки: `Заголовок`, `ШапкаТаблицы`, `Строка`, `Подвал`. Значение попадает в
ячейку, только если у ячейки заполнение "Параметр" (в `1c-mxl-compile` - ключ `param`) или "Шаблон"
(ключ `template`, текст вида `Накладная № [Номер] от [Дата]`). Ячейка с ключом `text` печатает
`[Номер]` буквально. Имя параметра совпадает с полем запроса или ключом структуры `ДанныеПечати`.

Путь к макету объекта конфигурации - `"Документ.<ИмяДокумента>.ПФ_MXL_<Имя>"`. Макет внешней
обработки берется методом самой обработки `ПолучитьМакет("ПФ_MXL_<Имя>")`.

## Вариант A: модуль менеджера объекта конфигурации

### 1. Регистрация объекта

Объект должен быть в списке объектов печати: общий модуль `УправлениеПечатьюПереопределяемый`,
процедура `ПриОпределенииНастроекПечати(Настройки)`, одна строка:

```bsl
	Настройки.ОбъектыПечати.Добавить(Документы.<ИмяДокумента>);
```

Сначала найди Grep по этому модулю: строка может уже быть. Конфигурация на поддержке или задача "в
расширении" - эту процедуру меняй перехватчиком `1c-cfe-patch-method` (`&После`), модуль менеджера
документа заимствуй `1c-cfe-borrow`.

В форму объекта ничего добавлять не нужно: подменю "Печать" в формах БСП строит подсистема
"Подключаемые команды" по процедуре `ДобавитьКомандыПечати`.

### 2. Модуль менеджера

Область `ПрограммныйИнтерфейс` модуля менеджера. Если в модуле уже есть `ДобавитьКомандыПечати` или
`Печать` - вторые не создавай: допиши свою команду и свой блок `Если` в существующие процедуры.

```bsl
#Область ПрограммныйИнтерфейс

// Переопределяет настройки печати для объекта.
//
// Параметры:
//  Настройки - см. УправлениеПечатью.НастройкиПечатиОбъекта.
//
Процедура ПриОпределенииНастроекПечати(Настройки) Экспорт
	
	Настройки.ПриДобавленииКомандПечати = Истина;
	
КонецПроцедуры

// Заполняет список команд печати.
//
// Параметры:
//  КомандыПечати - см. УправлениеПечатью.СоздатьКоллекциюКомандПечати.
//
Процедура ДобавитьКомандыПечати(КомандыПечати) Экспорт
	
	КомандаПечати = КомандыПечати.Добавить();
	КомандаПечати.Идентификатор                  = "ICOM_Накладная";
	КомандаПечати.Представление                  = "Накладная";
	КомандаПечати.ПроверкаПроведенияПередПечатью = Истина;
	КомандаПечати.Порядок                        = 50;
	
КонецПроцедуры

// Формирует печатные формы.
//
// Параметры:
//  МассивОбъектов - см. УправлениеПечатьюПереопределяемый.ПриПечати.МассивОбъектов
//  ПараметрыПечати - см. УправлениеПечатьюПереопределяемый.ПриПечати.ПараметрыПечати
//  КоллекцияПечатныхФорм - см. УправлениеПечатьюПереопределяемый.ПриПечати.КоллекцияПечатныхФорм
//  ОбъектыПечати - см. УправлениеПечатьюПереопределяемый.ПриПечати.ОбъектыПечати
//  ПараметрыВывода - см. УправлениеПечатьюПереопределяемый.ПриПечати.ПараметрыВывода
//
Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода) Экспорт
	
	Если УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, "ICOM_Накладная") Тогда
		УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(
			КоллекцияПечатныхФорм,
			"ICOM_Накладная",
			"Накладная",
			СформироватьПечатнуюФормуНакладная(МассивОбъектов, ОбъектыПечати),
			,
			"Документ.<ИмяДокумента>.ПФ_MXL_Накладная");
	КонецЕсли;
	
КонецПроцедуры

#КонецОбласти
```

Идентификатор команды и второй параметр `НужноПечататьМакет` и `ВывестиТабличныйДокументВКоллекцию` -
одна и та же строка. Последний параметр - полный путь к макету, по нему работает "Изменить макет" в
форме печати.

### 3. Функция формирования

Область `СлужебныеПроцедурыИФункции` того же модуля:

```bsl
Функция СформироватьПечатнуюФормуНакладная(МассивОбъектов, ОбъектыПечати)
	
	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	ДанныеДокумента.Ссылка КАК Ссылка,
		|	ДанныеДокумента.Номер КАК Номер,
		|	ДанныеДокумента.Дата КАК Дата,
		|	ДанныеДокумента.Контрагент КАК Контрагент,
		|	ДанныеДокумента.Товары.(
		|		НомерСтроки КАК НомерСтроки,
		|		Номенклатура КАК Номенклатура,
		|		Количество КАК Количество,
		|		Цена КАК Цена,
		|		Сумма КАК Сумма
		|	) КАК Товары
		|ИЗ
		|	Документ.<ИмяДокумента> КАК ДанныеДокумента
		|ГДЕ
		|	ДанныеДокумента.Ссылка В (&МассивОбъектов)
		|
		|УПОРЯДОЧИТЬ ПО
		|	ДанныеДокумента.Дата";
	Запрос.УстановитьПараметр("МассивОбъектов", МассивОбъектов);
	
	РезультатЗапроса = Запрос.Выполнить();
	Шапка = РезультатЗапроса.Выбрать();
	
	ТабличныйДокумент = Новый ТабличныйДокумент;
	ТабличныйДокумент.КлючПараметровПечати = "ПАРАМЕТРЫ_ПЕЧАТИ_ICOM_Накладная";
	
	Макет = УправлениеПечатью.МакетПечатнойФормы("Документ.<ИмяДокумента>.ПФ_MXL_Накладная");
	
	Пока Шапка.Следующий() Цикл
		
		Если ТабличныйДокумент.ВысотаТаблицы > 0 Тогда
			ТабличныйДокумент.ВывестиГоризонтальныйРазделительСтраниц();
		КонецЕсли;
		
		НомерСтрокиНачало = ТабличныйДокумент.ВысотаТаблицы + 1;
		
		ОбластьМакета = Макет.ПолучитьОбласть("Заголовок");
		ОбластьМакета.Параметры.Заполнить(Шапка);
		ТабличныйДокумент.Вывести(ОбластьМакета);
		
		ОбластьМакета = Макет.ПолучитьОбласть("ШапкаТаблицы");
		ТабличныйДокумент.Вывести(ОбластьМакета);
		
		ОбластьМакета = Макет.ПолучитьОбласть("Строка");
		СтрокиТоваров = Шапка.Товары.Выбрать();
		Пока СтрокиТоваров.Следующий() Цикл
			ОбластьМакета.Параметры.Заполнить(СтрокиТоваров);
			ТабличныйДокумент.Вывести(ОбластьМакета);
		КонецЦикла;
		
		ОбластьМакета = Макет.ПолучитьОбласть("Подвал");
		ОбластьМакета.Параметры.Заполнить(Шапка);
		ТабличныйДокумент.Вывести(ОбластьМакета);
		
		УправлениеПечатью.ЗадатьОбластьПечатиДокумента(
			ТабличныйДокумент,
			НомерСтрокиНачало,
			ОбъектыПечати,
			Шапка.Ссылка);
		
	КонецЦикла;
	
	Возврат ТабличныйДокумент;
	
КонецФункции
```

Поля запроса бери из выгрузки объекта (`1c-meta-info`): у табличной части может не быть `Сумма`, у
документа - `Контрагент`. Значения, которых нет в запросе (итог, сумма прописью), собери в структуру
`ДанныеПечати` и передай через `ЗаполнитьЗначенияСвойств(ОбластьМакета.Параметры, ДанныеПечати)`. Сумма
прописью - `ЧислоПрописью` платформы либо функция, которую ты нашел в выгрузке этой конфигурации.

## Вариант B: внешняя печатная форма

1. Обработка - `1c-epf-scaffold`, макет - `1c-template-add` и `1c-mxl-compile` (раздел "Макет").
2. Функция `СведенияОВнешнейОбработке()` - навыком `1c-bsp-registration`: вид "печатная форма",
   назначение `Документ.<ИмяДокумента>`. Навык задает команду с `ТипКомандыВызовСерверногоМетода()`,
   `Модификатор = "ПечатьMXL"` и идентификатором `МетаданныеОбработки.Имя`. Свою функцию регистрации не
   пиши.
3. Процедура `Печать` - в модуль объекта, область `ПрограммныйИнтерфейс`, после
   `СведенияОВнешнейОбработке()`:

```bsl
// Формирует печатные формы.
//
// Параметры:
//  МассивОбъектов - Массив - ссылки на объекты назначения.
//  КоллекцияПечатныхФорм - ТаблицаЗначений - описания печатных форм.
//  ОбъектыПечати - СписокЗначений - области объектов в табличном документе.
//  ПараметрыВывода - Структура - параметры вывода.
//
Процедура Печать(МассивОбъектов, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода) Экспорт
	
	ИдентификаторКоманды = Метаданные().Имя;
	Если УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, ИдентификаторКоманды) Тогда
		УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(
			КоллекцияПечатныхФорм,
			ИдентификаторКоманды,
			"Накладная",
			СформироватьПечатнуюФормуНакладная(МассивОбъектов, ОбъектыПечати));
	КонецЕсли;
	
КонецПроцедуры
```

У внешней формы ЧЕТЫРЕ параметра (`ПараметрыПечати` нет: так ее вызывает
`УправлениеПечатью.ПечатьПоВнешнемуИсточнику`), у модуля менеджера - ПЯТЬ. Имя в `НужноПечататьМакет` -
идентификатор команды из `СведенияОВнешнейОбработке()`.

4. Функция `СформироватьПечатнуюФормуНакладная` - как в варианте A, в области
   `СлужебныеПроцедурыИФункции` модуля объекта, с одной заменой - макет берется методом обработки:

```bsl
	Макет = ПолучитьМакет("ПФ_MXL_Накладная");
```

5. Сборка - `1c-epf-build`. В базе форма подключается так: Администрирование - Печатные формы, отчеты и
   обработки - Дополнительные отчеты и обработки - Добавить из файла.

## Чего не делать

- Не вызывать `УправлениеПечатью.ВыполнитьКомандуПечати` и не открывать `ОбщаяФорма.ПечатьДокументов`
  своей командой формы: печать запускает подменю "Печать".
- Не писать значения в ячейку текстом (`ОбластьМакета.Области...Текст = ...`): только параметры макета.
- Не выполнять запрос в цикле по документам: один запрос на весь `МассивОбъектов`, табличная часть -
  вложенной таблицей.
